About the Project

From Space to Action

This dashboard is a Minimum Viable Product (MVP) demonstrating an AI-powered Agricultural Drought Early Warning System for the Oromia region of Ethiopia.

Developer Information

  • Student: Kalkidan Wondimagegnehu Alemneh
  • Institution: EGATE (School of Gifted and Talented)
  • Discipline: Astronomy and Space Technology — Earth Observation

Methodology

The system utilizes multi-source Earth Observation data processed through Google Earth Engine (GEE). Key features including NDVI, VCI, and Rainfall anomalies are extracted and fed into advanced machine learning models (XGBoost, Random Forest, LSTM) to predict drought severity classes up to 30 days in advance.

Disclaimer: This is a research prototype built for educational and demonstration purposes. The data shown in this MVP mode is synthetically generated for demonstration. Do not use for official agricultural or disaster response planning.

Technology Stack

  • Python
  • Google Earth Engine API
  • Scikit-Learn & XGBoost
  • Flask Web Framework
  • Leaflet.js
  • Plotly.js
