🔷 Rule Baseline

Agronomic threshold model using VCI (<20 → Severe, <35 → Warning, <50 → Watch). Provides interpretable baseline for comparison.

🌲 Random Forest

300-tree ensemble classifier trained with class balancing. Provides robust feature importance via mean decrease in impurity.

⚡ XGBoost + SHAP

Gradient-boosted classifier with SHAP explainability. Best overall F1 on held-out test set. Includes 10/30-day lead time variants.

🧠 PyTorch LSTM

Bidirectional LSTM (2-layer, 128 units) processing 12-month rolling sequences. GPU-trained on Colab. Strong at long-lead predictions.
